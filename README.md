# Featherpull

yt-dlp と ffmpeg をラップした軽量GUIアプリケーション(Rust製)。

> 🚧 現在開発中です。詳細なドキュメントは今後追加していきます。

## フォント

UIフォントとして以下を同梱しています(いずれも [SIL Open Font License 1.1](https://openfontlicense.org/) で提供されており、ライセンス全文は `assets/fonts/` 内の各`*-OFL.txt`を参照):

- 英数字: [JetBrains Mono](https://www.jetbrains.com/lp/mono/)
- 日本語: [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)

上記でカバーされない文字(絵文字等)は、eguiに同梱されているフォントにフォールバックします。
